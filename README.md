# Exploratory Data Analysis in Python

This project explores rating trends for various chocolate bars based on their ingredients, percent cocoa, flavor profiles, bean origin, and manufacturer. It demonstrates the processes of data cleaning, exploratory analysis, and visualization in Python. 




## Usage


1. Clone this repository.

2. Install the required Python packages:
    pip install -r requirements.txt

3. Open the following two files in a Jupyter notebook.
    chocolate_bar_ratings_exploration.ipynb 
    chocolate_bar_ratings_plots.ipynb



## Example Output


One insight from this analysis indicates that most of the chocolate bars with 60-80% cocoa had ratings between 2.5 - 4.0.

Chocolate_bar_ratings_2022.csv (provided in repository)
